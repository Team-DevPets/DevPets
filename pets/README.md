# 여기에 펫 시트를 넣으세요

투명 배경 PNG 시트의 이름을 **sprite.png**로 바꿔 이 폴더에 넣으세요.
앱을 켜 둔 상태에서도 자동으로 적용됩니다. 이미지 사용이 꺼져 있다면 우클릭 메뉴의 **내 그림 쓰기**를 켜세요.

기존 토끼와 같은 11줄 형식이면 설정 파일 없이 9가지 동작과 16방향 시선을 자동 연결합니다.
1~9줄은 쉬기, 오른쪽 걷기, 왼쪽 걷기, 잡고 이동, 점프, 오류, 대기, 작업, 클릭 반응 순서입니다.
10~11줄에는 각 8장씩, 위쪽부터 시계 방향으로 22.5도 간격의 시선 그림이 있어야 합니다.

이 폴더의 sprite.png가 예전 사용자 폴더의 시트보다 우선합니다.
삭제하면 예전 사용자 시트로, 그것도 없으면 내장 우사기(usagi-v1.10)로 돌아갑니다.
보통 sprite.json은 필요하지 않습니다. 상세 형식과 선택 설정은 프로젝트의 README.md를 참고하세요.
