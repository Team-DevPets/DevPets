# Claude 책상 펫

바탕화면에 머물면서 커서를 바라보는 작은 펫입니다. 기본 캐릭터는 **우사기(usagi-v1.10)**입니다. 프로펠러 이동·노트북 작업·점프·16방향 시선을 포함한 현재 시트를 기본 이미지로도 내장했습니다. 별도의 시트를 넣지 않아도 바로 사용할 수 있습니다.

## 실행

### Windows 배포본 — Node.js 없이 실행

`UsagiPet-0.3.2-win32-x64.zip`을 **폴더째 압축 해제**하고 `UsagiPet.exe`를 실행하세요. 현재 우사기 v1.10, 차분한 동작, 16방향 시선, 작업·완료 상태 점, 고해상도 렌더링이 기본으로 포함되어 있습니다.

```text
UsagiPet-0.3.2-win32-x64/
  UsagiPet.exe
  pets/                 ← 새 시트를 sprite.png로 넣는 곳
  resources/            ← 기본 이미지와 앱 파일
  시작하기.txt
```

실행 파일만 따로 옮기면 실행되지 않습니다. 함께 들어 있는 DLL과 폴더를 모두 보관하세요. 이미지 교체는 **실행 파일 옆**의 `pets` 폴더에서 합니다. `sprite.png`가 없으면 내장 우사기를 사용합니다(예전 사용자 시트가 있으면 그 시트가 먼저 적용됩니다).

펫 실행 자체에는 Node.js가 필요 없습니다. 선택 기능인 Claude Code 작업 연결은 Node.js를 설치하고 배포본 폴더에서 `node hooks/install.js`를 실행한 뒤 Claude Code를 다시 시작하세요.

### 소스 코드로 실행 — 깃에서 클론한 경우

[Team-DevPets/DevPets](https://github.com/Team-DevPets/DevPets) 레포에는 **소스만** 들어 있습니다. Electron 런타임(`UsagiPet.exe`와 DLL들)은 파일 하나가 180MB로 GitHub의 100MB 제한을 넘어서 올리지 않았습니다. `npm install`이 받아 주므로 **Node.js 18 이상**만 설치되어 있으면 됩니다.

```bash
git clone https://github.com/Team-DevPets/DevPets.git
cd DevPets/resources/app
npm install
npm start
```

`package.json`은 레포 루트가 아니라 **`resources/app`** 안에 있습니다. 그 폴더가 곧 Electron 앱 본체여서 `npm` 명령은 모두 거기서 실행합니다.

| 명령 | 하는 일 |
| --- | --- |
| `npm start` | 펫 실행 |
| `npm test` | 자동 테스트 (상태 합치기 · Codex 작업 기록 읽기) |

#### 펫 시트 — 춤·싸움을 보려면 한 단계 더

소스로 실행하면 펫은 **`resources/app/pets/sprite.png`** 를 찾지만, 레포의 시트는 루트 `pets` 폴더에 있습니다. 그대로 실행하면 내장 기본 시트(`assets/default-pet.png`, 11줄)가 적용되어 춤·싸움 같은 동작이 나오지 않습니다. `resources/app`에서 한 번만 가져다 두세요.

```powershell
Copy-Item ..\..\pets . -Recurse
```

복사본을 따로 두고 싶지 않으면 복사 대신 연결해도 됩니다 (관리자 권한 없이 됩니다).

```powershell
New-Item -ItemType Junction -Path pets -Target ..\..\pets
```

#### Claude Code · Codex 상태 연동

**레포 루트**에서 아래를 실행하고 Claude Code를 다시 시작하세요. 제거는 `--uninstall`을 붙입니다.

```bash
node hooks/install.js
```

`resources/app`에서 `npm run hooks`를 써도 같습니다 (0.4.17부터 루트의 `hooks/install.js`를 가리킵니다). 제거는 `npm run hooks:remove`입니다.

### Windows 배포본 다시 만들기

Windows x64에서 `resources/app`에 들어가 `npm install` 후 `npm run package:win`을 실행하세요. 레포 루트의 `release/UsagiPet-<버전>-win32-x64`에 실행 파일과 필요한 파일이 모두 생깁니다.

```bash
cd resources/app
npm install
npm run package:win
```

- Electron 런타임을 복사하고 `electron.exe`를 `UsagiPet.exe`로 바꾼 뒤, `resources/app`에 앱 소스를, 그 옆에 `pets` · `hooks` · `README.md` · `패치노트.md` · `시작하기.txt` · `업데이트-방법.txt`를 담습니다.
- `node_modules`, 시트 백업(`sprite-before-*.png`), 개발용으로 넣어 둔 `resources/app/pets`는 담지 않습니다.
- 같은 이름의 출력 폴더가 이미 있으면 멈춥니다. 지우고 다시 만들려면 `npm run package:win -- --force`를 쓰세요.
- 아이콘은 Electron 기본 아이콘을 씁니다. 시작 메뉴 바로 가기와 알림용 앱 ID는 배포본을 처음 실행할 때 앱이 직접 만듭니다.

배포할 때는 그 폴더 전체를 ZIP으로 묶으세요. 개인 설정과 개발용 `node_modules`는 배포본에 포함하지 않습니다.

## 펫 이미지 바꾸기 — 가장 쉬운 방법

1. 펫을 우클릭하거나 트레이 메뉴에서 **펫 시트 넣는 폴더 열기**를 누르세요. 프로젝트의 `pets` 폴더가 열립니다.
2. 기존 토끼와 같은 **11줄짜리 투명 배경 PNG 시트**를 준비하세요.
3. 파일 이름을 **sprite.png**로 바꾸고 그 폴더에 넣으세요. 이미 파일이 있으면 교체하세요.
4. 실행 중인 펫에 보통 2초 안에 자동 적용됩니다. 이미지 사용을 꺼 두었다면 메뉴의 **내 그림 쓰기**를 켜세요.

```text
claude_pet/
  pets/
    README.md
    sprite.png       ← 여기에 넣으세요
```

**같은 형식이면 sprite.json을 만들 필요가 없습니다.** 시선과 동작을 자동 연결합니다. 새 캐릭터로 교체할 때 이전에 직접 만든 `pets/sprite.json`이 있다면 함께 확인하세요. 그 파일의 동작 배정은 자동 배정보다 우선합니다.

### 시트 형식과 동작 대응

각 줄에는 아래 순서의 그림이 왼쪽에서 오른쪽으로 놓여 있어야 합니다. 아래 장수는 기존 토끼 시트 기준입니다. 동작 줄의 장수는 달라도 되지만, 시선 두 줄은 각각 8장이어야 합니다.

| 줄 번호 | 기존 시트 장수 | 그림 내용 | 사용 상황 |
| --- | --- | --- | --- |
| 1 | 6 | 쉬기 | 평소 / 커서가 펫 중심에 있을 때 |
| 2 | 8 | 오른쪽 이동 — 현재 우사기는 프로펠러 | 오른쪽 산책 이동 |
| 3 | 8 | 왼쪽 이동 — 현재 우사기는 프로펠러 | 왼쪽 산책 이동 |
| 4 | 4 | 공중에 들린 동작 — 토끼는 프로펠러 | 마우스로 잡고 옮기는 동안 반복 |
| 5 | 5 | 점프 | 놓을 때 / 작업 완료 시 한 번 |
| 6 | 8 | 오류 — 토끼는 빨간 표정 | 멀리 있을 때 오류 상태가 유지되는 동안 반복 |
| 7 | 6 | 기다리기 | 멀리 있을 때 대기 상태가 유지되는 동안 반복 |
| 8 | 6 | 작업 — 우사기는 노트북 | 멀리 있을 때 작업 상태가 유지되는 동안 반복 |
| 9 | 6 | 손동작 | 클릭하면 한 번 |
| 10 | 8 | 시선 방향 앞 절반 | 위쪽부터 시계 방향 0°~157.5° |
| 11 | 8 | 시선 방향 뒤 절반 | 시계 방향 180°~337.5° |

시선 각도는 **0° 위, 90° 오른쪽, 180° 아래, 270° 왼쪽**입니다. 각 그림은 22.5° 간격이며 시선 줄을 애니메이션처럼 순서대로 재생하지 않습니다. 커서 각도에 맞는 그림 하나를 선택합니다.

배경은 투명해야 하고, 이웃한 프레임과 줄 사이에 투명한 간격이 있어야 합니다. JPG, 불투명 배경, 그림끼리 붙어 있는 시트는 자동으로 분리되지 않을 수 있습니다. 픽셀 크기는 기존 시트와 같을 필요가 없습니다.

### 어떤 이미지가 우선 적용되나요?

1. 프로젝트의 `pets/sprite.png`
2. 예전 사용자 폴더의 `~/.claude-desk-pet/sprite.png`
3. 내장 우사기(usagi-v1.10) `assets/default-pet.png`

`~`는 사용자 홈 폴더입니다. Windows에서는 보통 `C:\Users\사용자이름`입니다. **프로젝트에 넣은 시트에는 예전 사용자 폴더의 sprite.json을 적용하지 않습니다.** 각 이미지와 같은 폴더의 설정만 읽습니다.

`pets/sprite.png`를 지우면 다음 우선순위 이미지로 자동 복귀합니다. 시트와 설정 파일을 추가·교체·삭제하면 재시작 없이 반영됩니다. 앱 코드를 처음 업데이트한 직후에는 한 번 완전히 종료하고 다시 실행하세요.

## 조작과 기본 동작

| 조작 | 반응 |
| --- | --- |
| 커서 움직이기 | 가까이 오면 16방향 시선 추적, 멀어지면 현재 상태 모션 |
| 머리나 몸을 잡고 드래그 | 잡은 지점을 따라 이동하며 4번째 줄 동작 재생 |
| 놓기 | 점프를 한 번 보여주고 원래 상태로 돌아오기 |
| 클릭 | 손동작과 짧은 말풍선 |
| 우클릭 / 트레이 | 설정 열기, 펫 숨기기, 자동 산책, 혼잣말, 크기, 종료 |
| 트레이 아이콘 더블클릭 · UsagiPet.exe 다시 실행 | 설정 창(컨트롤센터) 열기 |
| 트레이 아이콘에 마우스 올리기 | 현재 작업 상태 (여러 세션이면 세션 수) |

기본은 높이 90px의 차분한 모드입니다. 우클릭 또는 트레이 메뉴의 **크기**에서 작게(70)·보통(90)·크게(110)·아주 크게(130)를 고를 수 있고, 발 위치는 그대로 둔 채 위쪽으로 커집니다. 모든 동작은 쉬기 그림과 같은 배율로 그려서 프로펠러처럼 큰 소품이 있어도 몸 크기가 줄지 않으며, 점프처럼 공중에 뜬 그림은 시트에 그려진 높이만큼 실제로 떠오릅니다. 자동 산책과 혼잣말은 기본으로 꺼져 있으며, 우클릭 또는 트레이 메뉴에서 각각 체크해 켜고 끌 수 있습니다. 선택은 저장되며 앱을 다시 켜도 유지됩니다. 자동 산책은 켜면 8~20초마다 한 번에 150~500px씩 걸어서 이동하고(시트 2·3번째 줄), 끄면 즉시 멈춥니다. 혼자 걸을 때는 몸 전체가 화면 안에 있는 범위에서만 움직이며, 가장자리에 걸쳐 있으면 안쪽으로 걸어 들어옵니다. 손으로 잡아 옮길 때는 4번째 줄(현재 우사기는 프로펠러)을 씁니다. 혼잣말은 켜면 약 25초마다 확률적으로 표시되며, 꺼도 직접 클릭할 때의 말풍선은 나옵니다. 하트 효과는 꺼져 있습니다. 모션을 3~4초만 보여주는 시간 제한은 없습니다. 커서가 펫 중심 약 140px 안으로 들어오면 시선을 추적하고, 약 180px 밖으로 나가면 현재 상태의 기본 모션으로 돌아갑니다. 경계에서 모션이 깜빡이지 않도록 진입·이탈 거리를 다르게 설정했습니다. 멀리 있을 때 작업·대기·오류 모션은 해당 상태가 유지되는 동안 반복합니다. 완료 시 점프는 한 번만 보여준 뒤 쉬기로 돌아가며, 드래그·클릭·착지 반응은 시선 추적보다 우선합니다.

### 우사기의 말

우사기는 말을 못 해서 외침만 합니다. 뜻은 말풍선 아래 괄호 안에 작게 적을 수 있고, 우클릭 메뉴 **말풍선 설정**에서 따로 켜고 끕니다.

| 메뉴 | 대상 | 기본 |
| --- | --- | --- |
| 우사기어 해석 | 쓰다듬기·혼잣말·인사 | 꺼짐 — 예: **우라우라~** |
| AI 결과 우사기어 해석 | AI 작업·확인 대기·오류·완료, 아이콘 클릭 안내 | 켜짐 — 예: **하아?** (이거 해도 돼? 확인해 줘! / 명령 실행 해도 돼?) |

같은 메뉴의 **혼잣말**을 켜야 혼잣말과 AI 상태 말풍선이 나옵니다. 쓰다듬기 말풍선은 혼잣말이 꺼져 있어도 나옵니다.

| 우사기 말 | 뜻 |
| --- | --- |
| 야하 | 신날 때·반가울 때 |
| 후응 | 맞아 (긍정) |
| 우~라~ | 거대하다 / 엄청난 걸 봤을 때 감탄 |
| 하아? | 뭐냐고 물을 때·깜짝 놀랐을 때·짜증 날 때 |
| 우아(우마) | 맛있다 |
| 우냐 | 가자! |
| 우라우라 | 가보자고! / 기분이 좋을 때 |
| 푸루루 | 흥얼흥얼 |

AI 소식에는 지금 하는 일도 괄호 안에 함께 적습니다. 예: **우냐!** (가자! AI가 일하는 중 / 명령 실행). AI 도구 이름은 읽기 쉬운 말로 바꿉니다 (Bash → 명령 실행, Read → 파일 읽기 등). 말풍선은 펫 위 남은 공간만큼 늘어나고, 글이 길수록 오래 떠 있습니다(최대 9초).

캐릭터 오른쪽 아래에는 10px 상태 점이 살짝 겹쳐 표시됩니다. 작업 중에는 파란 점, 입력 대기는 노란 점, 오류는 빨간 점이며, 완료되면 초록 점을 3초 보여준 뒤 숨깁니다. 가까이 와서 시선 추적 중이어도 실제 작업이 진행 중이면 파란 점은 유지됩니다.

| 상태 | 캐릭터 동작 | 우측 하단 점 |
| --- | --- | --- |
| 평소 | 16방향 시선 추적 | 없음 |
| 작업 중 | 멀면 노트북 반복, 가까우면 시선 추적 | 작업이 끝날 때까지 파란 점 유지 |
| 완료 | 작업 동작을 즉시 끊고 점프 한 번 | 초록 점 3초 후 숨김 |
| 입력 대기 | 멀면 대기 반복, 가까우면 시선 추적 | 노란 점 유지 |
| 오류 | 멀면 오류 반복, 가까우면 시선 추적 | 빨간 점 유지 |

상태 점은 깜빡이지 않으며, 이미지의 크기와 위치에 맞춰 캐릭터 우측 하단에 붙습니다.

펫의 표시 크기는 유지하면서 내부 캔버스를 최소 2배 해상도로 그립니다. 화면 배율이 200%보다 높으면 해당 배율에 맞춰 더 높이고, 다른 배율의 모니터로 옮겨도 자동으로 갱신합니다. 이미지 축소에는 고품질 보간을 사용합니다.

펫이 보이는 불투명한 부분만 클릭·드래그를 받습니다. 시선 추적 범위나 펫 주변의 투명한 공간에서는 뒤쪽 프로그램을 그대로 클릭할 수 있으며, 말풍선과 상태 점은 클릭을 막지 않습니다.

펫을 화면 위쪽 끝까지 올릴 수 있습니다. 말풍선은 펫과 약 10px 간격으로 붙고, 위쪽 공간이 부족하면 아래에 표시됩니다.

## Claude Code 작업 상태 연결

가장 쉬운 방법은 펫 우클릭(또는 트레이) 메뉴의 **Claude Code 작업 알림 연결**을 체크하는 것입니다. 다시 누르면 연결이 해제됩니다. 명령어로 하려면 한 번 실행하세요.

```bash
npm run hooks        # 배포본 폴더에서는 node hooks/install.js
```

`~/.claude/settings.json`에 hooks를 추가합니다. 기존 설정은 보존하고, 처음 바꿀 때 `settings.json.pet-backup`으로 원본을 한 번 백업합니다. 설정 파일이 올바른 JSON이 아니면 아무것도 바꾸지 않고 멈춥니다. 실행 중인 Claude Code는 다시 시작해야 적용됩니다.

hook 스크립트는 `~/.claude-desk-pet/hooks/pet-status.js`로 복사해서 등록하므로 앱 폴더를 옮겨도 연결이 끊기지 않습니다. 앱을 업데이트한 뒤에는 연결을 한 번 껐다 켜면 새 스크립트로 바뀝니다. hook 실행에는 Node.js가 필요하며, 메뉴에서 연결할 때 Node.js가 없으면 안내합니다. 도구 실행 전후처럼 자주 오는 이벤트는 백그라운드(`async`)로 실행해 Claude Code를 기다리게 하지 않습니다.

| Claude Code 상태 | 펫 반응 |
| --- | --- |
| 프롬프트 보냄 / 도구 실행 중 | 멀면 노트북 반복 — 완료되면 즉시 전환 |
| 권한 승인 대기 / 질문 | 멀면 대기 그림 반복, 답할 때까지 노란 점 유지 (최대 2시간) |
| 답변 완료 | 점프 한 번 |
| API 오류로 응답 중단 (사용량 한도·서버 혼잡 등) | 멀면 오류 그림 반복, 다음 프롬프트까지 빨간 점 유지 (최대 2시간) |
| 세션 종료 / 5분간 작업 소식 없음 | 쉬기와 시선 추적 |

**여러 세션을 동시에 써도** 서로 덮어쓰지 않습니다. 세션마다 `~/.claude-desk-pet/sessions/<세션ID>.json`에 따로 기록하고, 펫은 **확인 대기 > 오류 > 작업 중 > 완료** 순서로 가장 급한 상태를 보여줍니다. 한 세션이 끝나도 다른 세션이 작업 중이면 노트북을 계속 두드리고, 세션마다 완료될 때 점프합니다. 도구 하나가 실패하는 것은 흔한 일이라 오류로 보지 않습니다. 답변 후 한참 입력이 없을 때 오는 알림(idle_prompt)은 이미 완료로 알렸으므로 노란 점을 다시 켜지 않습니다.

연결 제거:

```bash
npm run hooks:remove   # 배포본 폴더에서는 node hooks/install.js --uninstall
```

## Codex 작업 상태 연결

Codex(CLI·앱·IDE)도 Claude Code와 같은 형식의 hooks를 지원해서 같은 방식으로 연결합니다. 펫 우클릭 메뉴의 **Codex 작업 알림 연결**을 체크하세요. 명령어로는 `node hooks/install.js --codex`(해제는 `--codex --uninstall`)입니다. `~/.codex/hooks.json`에 등록하고, 기존 항목은 보존합니다.

**처음 한 번은 Codex에서 신뢰(trust)해야 실행됩니다.** Codex CLI에서 `/hooks`를 입력해 펫 hook을 검토하고 신뢰하세요. 프롬프트 보냄·도구 실행 중이면 작업, 권한 요청이면 대기, 답변 완료면 점프, 작업을 멈추면(Interrupt) 쉬기로 돌아갑니다. Codex 세션은 `sessions/codex-<세션ID>.json`으로 따로 기록되어 Claude Code·Claude 앱 상태와 함께 합쳐집니다.

## 데스크톱 채팅 앱 응답 감지 — Claude 앱 · ChatGPT 앱 (Windows)

Claude 데스크톱 앱과 ChatGPT 데스크톱 앱에는 외부 연결(hooks) 기능이 없어서, 앱 폴더의 `resources/app/app-watch.ps1`이 Windows 접근성 기능(UI Automation)으로 앱 창의 버튼을 읽습니다.

- 답변하는 동안에만 보이는 **중지 버튼**(예: "응답 중지", "중지", "Stop")이 있으면 작업 중, 이어서 사라지면 완료 (Claude 앱 2초, ChatGPT 앱 5초 — ChatGPT 앱은 답변 중간에 버튼을 잠깐 숨길 때가 있음)
- 작업 도중 **허용·승인 버튼**이 보이면 확인 대기 (설정 화면의 같은 이름 버튼과 헷갈리지 않도록, 최근 15분 안에 답변하던 앱일 때만)
- ChatGPT 앱은 일반 채팅과 앱 안의 Codex 화면을 모두 같은 방식으로 감지합니다.

우클릭 메뉴의 **Claude 앱 응답 감지**, **ChatGPT 앱 응답 감지**로 각각 켜고 끄며, 기본으로 켜져 있습니다.

- 부담을 줄이려고 화면 전체 확인은 앱이 움직일 때(CPU 사용), 쉬는 중엔 10초마다, 답변 중엔 3초마다만 합니다. 한 번에 보통 수십 ms가 걸립니다.
- 창이 다른 창 뒤에 있거나 최소화돼 있어도 됩니다. 트레이로 닫아 둔 창도 찾아보지만, 앱이 숨긴 화면의 버튼을 내놓지 않으면 감지되지 않습니다 (로그에 `(hidden)`으로 표시).
- 앱 화면이 바뀌어 버튼 이름이 달라지면 감지가 안 될 수 있습니다. 감지 기록은 앱 폴더의 `logs/app-watch.log`에 남고, 처음 보는 중지·취소·허용 계열 버튼 이름도 `candidates=`로 기록됩니다. 버튼 이름은 `config.json`의 `stopPatterns`, `approvePatterns`로 바꿀 수 있습니다 (정규식, 대소문자 무시). 예: `"stopPatterns": { "chatgpt": "^(스트리밍 중지|stop streaming)$" }`
- Claude Code CLI(`claude.exe`)는 이 감지에서 빠지고 hooks로 따로 연결됩니다. Codex CLI도 hooks로 연결하면 더 정확합니다.

## AI 상태 표시 (Claude · GPT)

Claude(Claude 앱·Claude Code)와 GPT(ChatGPT 앱·Codex)는 각자 아이콘으로 캐릭터 곁에 나타나, **어느 AI가 무엇을 하는지** 따로 보여 줍니다. 우클릭 메뉴의 **작업 중인 AI 아이콘 돌리기**로 끄고 켭니다.

| AI 상태 | 아이콘 |
| --- | --- |
| 작업 중 | 캐릭터 둘레를 타원으로 돎 (3.2초에 한 바퀴), 파란 호가 도는 링. 뒤쪽 반바퀴는 캐릭터 뒤로 지나감 |
| 확인 대기 | 머리 옆 자리(Claude 왼쪽, GPT 오른쪽)에 멈춰 살짝 떠 있음, 노란 링이 퍼지고 `!` 표시 |
| 오류 | 머리 옆 자리에 멈춰 한 번 흔들림, 빨간 링과 `!` 표시 |
| 완료 | 초록 링으로 한 번 커졌다가 위로 떠오르며 사라짐 (캐릭터는 점프) |

- 처음 나타날 때는 캐릭터 가운데에서 나선을 그리며 퍼져 나가고, 상태가 바뀌면 순간이동하지 않고 부드럽게 자리를 옮깁니다.
- Windows의 "애니메이션 효과" 설정을 끄면(동작 줄이기) 궤도를 돌지 않고 머리 옆에 멈춘 채 링 색으로만 상태를 보여 줍니다.
- AI 아이콘이 상태를 보여 주는 동안에는 오른쪽 아래 상태 점을 겹쳐 띄우지 않습니다. 외부 프로그램이 `status.json`으로 보낸 상태일 때만 점이 보입니다.

**마우스를 올리면** 0.35초 뒤에 상태 카드가 뜹니다. AI마다 어디서(Claude 앱·Claude Code·ChatGPT 앱·Codex), 무슨 상태인지, 이번 작업이 몇 분째인지, 확인할 내용이 무엇인지 보여 줍니다. 트레이 아이콘에 마우스를 올려도 같은 내용이 짧게 보입니다.

**아이콘에 마우스를 올리면** 궤도가 멈추고 그 아이콘이 1.35배로 커져 캐릭터 앞으로 나옵니다. 마우스를 떼면 멈춘 자리에서 이어서 돕니다. **도는 아이콘을 누르면** 그 AI의 데스크톱 앱이 앞으로 옵니다 (Microsoft Store 앱도 지원). 터미널에서 도는 Claude Code·Codex라면 "터미널을 확인해 주세요"라고 알려 줍니다.

### 완료 · 확인 대기 알림 (Windows)

다른 일을 하는 동안 AI가 끝났거나 확인을 기다리면 Windows 알림으로 알려 줍니다. 알림을 누르면 그 앱이 앞으로 옵니다. 우클릭 메뉴의 **AI 완료·확인 대기 알림**으로 끕니다.

- 그 앱 창이 이미 맨 앞에 있으면 알리지 않습니다 (보고 있으니까).
- 완료: 데스크톱 앱은 15초 이상, 터미널(Claude Code·Codex)은 60초 이상 걸린 작업만 알립니다. 알림에 걸린 시간이 함께 나옵니다.
- 확인 대기: 15초 넘게 그대로일 때만 알립니다. 오류는 3초 뒤에 알립니다.
- Windows "방해 금지"(집중 모드) 중에는 알리지 않습니다.

### 아이콘 그림

1. `pets/icons/claude.png`, `pets/icons/gpt.png` — 직접 넣은 그림 (정사각형 투명 PNG 권장, 넣거나 바꾸면 2초 안에 적용)
2. PC에 설치된 Claude 앱·ChatGPT 앱의 아이콘 (Windows). Microsoft Store 앱은 앱 패키지의 로고 그림을 씁니다. 어떤 아이콘을 어디서 가져왔는지는 `logs/app-watch.log`와 `logs/icon-claude.png`·`logs/icon-gpt.png`에 남습니다.
3. 둘 다 없으면 글자 배지(C, G)

흰색 위주의 로고(어두운 작업 표시줄용)는 자동으로 어두운 원 위에 그립니다.

## 선택 설정

### 일반 설정

`~/.claude-desk-pet/config.json`에서 설정합니다.

```json
{
  "species": "rabbit",
  "name": "우사기",
  "useSprite": true,
  "calmMode": true,
  "wander": false,
  "chatter": false,
  "size": 90,
  "watchClaudeApp": true,
  "watchChatGPTApp": true,
  "orbit": true,
  "notify": true,
  "meaningBasic": false,
  "meaningAI": true,
  "claudePath": ""
}
```

`claudePath`가 비어 있으면 설치된 Claude를 찾습니다. 못 찾으면 웹 Claude를 엽니다. `size`는 펫 높이(70·90·110·130 중 하나, 메뉴의 크기와 같음)이며 비워 두면 `calmMode`일 때 90px입니다. `wander`는 자동 산책, `chatter`는 혼잣말 설정이며 차분한 모드에서도 각각 켤 수 있습니다. 일반 설정 파일을 직접 수정했다면 앱을 다시 시작하세요.

### 시트 설정 — 필요할 때만

`pets/sprite.png`를 사용한다면 같은 폴더에 `pets/sprite.json`을 만드세요. 아래는 11줄 시트의 기본 동작 배정입니다. `rows` 번호는 위 표와 달리 **0부터** 셉니다.

```json
{
  "rows": {
    "idle": 0,
    "walk": 1,
    "walkLeft": 2,
    "dragging": 3,
    "done": 4,
    "error": 5,
    "waiting": 6,
    "working": 7,
    "review": 8
  },
  "fps": 6,
  "fpsByMood": { "walk": 10, "done": 8 },
  "height": 120
}
```

필요한 항목만 적어도 됩니다. 11줄 형식에서는 빠진 동작을 기본 배정으로 채웁니다. 한 동작이 여러 줄이면 `"dance": [15, 16, 17]`처럼 배열로 적습니다. `fpsByMood`를 적으면 기본값 전체를 바꾸므로 싸움(fight: 10)·춤(dance: 10)도 함께 적으세요. `fps`는 초당 프레임 수입니다. 차분한 모드에서 쉬기는 초당 2프레임, 높이는 90px로 고정되며, `height`는 차분한 모드를 끈 경우 적용됩니다.

11줄 형식이 아닌 예전 시트는 기존 방식으로 1~6줄을 쉬기·작업·대기·완료·오류·걷기에 배정합니다. 그런 시트에는 16방향 시선이 없으므로 작은 기울기 반응을 사용합니다.

## 직접 상태 보내기

다른 프로그램에서 `~/.claude-desk-pet/status.json`에 기록할 수도 있습니다.

```json
{ "mood": "waiting", "detail": "확인해줘", "at": 1792537200000 }
```

`mood`는 `idle`, `working`, `waiting`, `done`, `error` 중 하나이고, `at`은 현재 시각의 밀리초 타임스탬프입니다. 5분 지난 작업·완료 상태와 2시간 지난 대기·오류 상태는 쉬기로 처리됩니다. Claude Code 세션 상태(`sessions` 폴더)와 함께 위 우선순위로 합쳐집니다.

## 0.4.17에서 바뀐 점

- `resources/app/scripts/package-win.js`를 새로 넣었습니다. `package.json`의 `package:win`이 이 파일을 가리키고 있었지만 파일이 없어 `npm run package:win`이 실패했습니다. 이제 Electron 런타임(`node_modules/electron/dist`)을 복사하고 `electron.exe`를 `UsagiPet.exe`로 바꾼 뒤, `resources/app`에 앱 소스를, 앱 폴더에 `pets` · `hooks` · 설명 파일들을 담아 `<루트>/release/UsagiPet-<버전>-win32-x64`를 만듭니다.
  - `default_app.asar`, `node_modules`, 시트 백업(`sprite-before-*.png`), 개발용 `resources/app/pets`는 담지 않습니다.
  - 출력 폴더가 이미 있으면 멈추고, `npm run package:win -- --force`로 지우고 다시 만듭니다.
  - 아이콘은 Electron 기본 아이콘입니다(rcedit 없이 바꿀 수 없음). 시작 메뉴 바로 가기와 앱 ID는 앱이 처음 실행될 때 `ensureAppIdentity`가 만듭니다.
