# 우사기 펫 패치노트

버전마다 바뀐 점을 최신 버전부터 정리했습니다.
지금 버전은 설정 창 **일반 → 버전 정보**에서 볼 수 있습니다.

## 0.4.19 — 귀 팔랑 두 배로

**바뀐 점**
- 귀 팔랑이 두 배로 길어졌습니다. 팔랑팔랑 두 번 → 쫑긋 세 번으로, 약 4.9초입니다 (전에는 2.1초).
- 대사를 바꿨습니다. 팔랑팔랑할 때 "푸루 푸루~", 귀를 쫑긋 세울 때 "푸루루루루루~!"

## 0.4.18 — 귀 팔랑

**새 기능**
- 우사기가 귀를 좌우로 팔랑팔랑 털다가, 마지막에 귀를 쫑긋 세우고 휙휙 돌리는 동작이 생겼습니다. 약 2.1초이고 "푸루루~"(귀가 간질간질) 하다가 "야하!"(귀 쫑긋! 뭔가 들렸나?) 합니다.
- 쉬고 있을 때 가끔 혼자 합니다. 설정 창 **상호작용 → 귀 팔랑**에서 끄고 켤 수 있고, 그 자리의 **지금 해 보기**로 바로 볼 수 있습니다.

## 0.4.17 — 배포본 만들기 되살림 (개발용)

**버그 수정**
- 개발용 명령 두 개가 없는 파일을 찾아 실패하던 것을 고쳤습니다. 이제 `npm run package:win`으로 배포본 폴더를 다시 만들 수 있고, `npm run hooks`로 작업 상태 연동도 설치됩니다.

펫의 동작과 모습은 0.4.16과 같습니다.

## 0.4.16 — 다리 꼰 자세 0.5초로

**바뀐 점**
- "쁘릿!" 하고 다리를 다 꼰 뒤 멈춰 있는 시간을 1초에서 0.5초로 줄였습니다. 춤 전체는 약 7.1초입니다.

## 0.4.15 — 다리 꼰 자세 1초 유지

**바뀐 점**
- "쁘릿!" 하고 다리를 다 꼰 뒤 그 자세로 1초 동안 멈춰 있다가 춤이 끝납니다. 춤 전체는 약 7.6초입니다.

## 0.4.14 — 춤 마무리 시간 조정

**바뀐 점**
- "쁘릿!" 전에 서서 가만히 있는 시간을 1초 줄였습니다 (약 2.5초 → 1.5초).
- 다리를 다 꼰 뒤 멈춰 있던 2초를 없애, 다리를 꼬고 "쁘릿!" 하면서 바로 춤이 끝납니다. "쁘릿!" 말풍선은 춤이 끝난 뒤에도 잠깐(약 1.8초) 남아 있습니다.
- 춤 전체는 약 6.6초입니다.

## 0.4.13 — "쁘릿!"

**바뀐 점**
- 다리를 꼴 때 대사를 "쁘릿"에서 "쁘릿!"으로 바꿨습니다.

## 0.4.12 — "쁘릿" 전에 잠깐 멈추기

**바뀐 점**
- 몸 흔들기가 끝나고 다리를 꼬기 전에 서서 가만히 있는 시간을 2초 늘렸습니다 (약 0.5초 → 2.5초). 그다음 다리를 꼬면서 "쁘릿"이라고 말합니다. 춤 전체는 약 9.6초입니다.

## 0.4.11 — 다리 꼬고 "쁘릿"

**새 기능**
- 춤의 마지막에 다리 꼬기 동작을 더했습니다. 몸 흔들기가 끝나면 똑바로 섰다가 다리를 꼬면서 "쁘릿"이라고 말하고, 다리를 다 꼰 자세로 2초 동안 멈춰 있습니다.
- 이제 춤은 주먹질 8번 → 몸 흔들기 → 다리 꼬기 순서이며, 전체 약 7.6초입니다.

**개선**
- 춤 대사 말풍선이 다음 대사가 나올 때까지 사라지지 않고, 마지막 "쁘릿"은 춤이 끝날 때까지 떠 있습니다.

## 0.4.10 — 주먹질 딱 8번

**바뀐 점**
- 춤출 때 주먹을 딱 8번 뻗습니다 (약 2.3초). 그동안 "우 우나나 우나~"라고 말하고, 그다음 몸 흔들기로 넘어갑니다. 춤 전체는 약 4.8초입니다.

## 0.4.9 — 주먹질 두 배

**바뀐 점**
- 춤의 주먹질 부분이 두 배로 길어졌습니다 (약 0.8초 → 1.6초). 주먹질 동작을 두 번 이어서 한 뒤 몸 흔들기로 넘어가며, 그동안 "우 우나나 우나~"라고 말합니다. 춤 전체는 약 4.1초입니다.

## 0.4.8 — 춤 대사

**바뀐 점**
- 춤출 때 대사가 동작에 맞춰 바뀝니다. 주먹질할 때는 "우 우나나 우나~", 몸을 흔들 때는 "우나나 야하야하~~"라고 말합니다.

## 0.4.7 — 잠옷 춤

**새 기능**
- 잠옷 차림 우사기의 춤 동작(33프레임)을 넣었습니다. 손을 흔들며 들썩이다가, 웅크렸다 좌우로 기울며 흔들고, 다시 웅크리며 끝납니다. 약 3.3초 동안 재생됩니다.
- "갑자기 춤추기" 상호작용에서 몸 흔들기 효과 대신 이 춤을 춥니다.

**바뀐 점**
- 시트 16~21번째 줄이 춤 동작이 되면서, 먹기·도토리·낮잠·반기기·잰걸음 그림은 정해진 줄이 없어졌습니다. 나중에 그림을 붙이면 `pets\sprite.json`에서 줄 번호를 정해 줍니다.
- 이전 시트는 `pets\sprite-before-dance.png`로 남겨 두었습니다.

## 0.4.6 — 8방향 산책

**새 기능**
- 자동 산책 중에 위아래와 대각선으로도 걷습니다. 좌우로 가장 자주 걷고, 대각선은 그다음, 위아래는 가끔 걷습니다.
- "휘저으면 도망가기"도 커서 반대쪽으로 대각선까지 달아납니다.
- 설정 창 **모습·움직임 → 위아래·대각선으로도 걷기**를 끄면 예전처럼 좌우로만 걷습니다.

**개선**
- 몸 전체가 화면 안에 있는 범위에서만 움직이고, 화면 가장자리에 붙어 있으면 그쪽으로는 걷지 않습니다.
- 대각선으로 걸을 때는 가로 방향을 바라보고, 위아래로만 걸을 때는 직전에 보던 쪽을 바라봅니다.

## 0.4.5 — 상호작용 전용 그림

**새 기능**
- 상호작용 전용 그림(먹기·춤·도토리 닦기·낮잠·반기기·잰걸음)을 시트에 넣으면 바로 씁니다. 그림이 없는 행동은 예전처럼 기존 동작에 효과를 얹어 보여 줍니다.
- 설정 창 **상호작용**에서 행동마다 "전용 그림"을 쓰는지, "효과로 대신"하는지 보여 줍니다.

## 0.4.4 — 점검

**개선**
- 펫 화면이나 설정 창에서 오류가 나면 감지 기록(`logs\app-watch.log`)에 남깁니다. 같은 오류는 1분에 한 번만 남깁니다.

**버그 수정**
- 대화를 스크롤하기만 해도 감지 기록이 계속 쌓이던 문제를 고쳤습니다.

## 0.4.3 — ChatGPT 채팅 완료를 1초 만에

**개선**
- 실제 앱의 버튼 이름에 맞춰, ChatGPT 채팅이 끝나면 약 1초 만에 완료로 바뀝니다. 예전에는 5초를 기다렸습니다.

## 0.4.2 — 채팅 완료를 더 빨리 알아채기

**개선**
- ChatGPT·Claude 앱 채팅의 완료를 더 빨리 알아챕니다. 답이 끝나면 생기는 복사·좋은 응답 같은 버튼이 늘었으면 기다리지 않고 바로 완료로 봅니다.
- 답하는 도중 중지 버튼이 잠깐 숨어도 완료로 착각하지 않습니다.

## 0.4.1 — Codex 상태 정확도

**버그 수정**
- ChatGPT 앱 창이 다른 창에 가려져 있으면, Codex 작업이 끝난 뒤에도 한참 동안 "작업 중"으로 보이던 문제를 고쳤습니다. 이제 작업 기록이 끝나는 즉시 완료로 바뀝니다.

**개선**
- AI별 상태가 바뀔 때마다 감지 기록에 한 줄씩 남겨, 문제가 생겼을 때 확인하기 쉬워졌습니다.

**알아 두기**
- ChatGPT 일반 채팅은 화면을 보고 상태를 알아냅니다. 창이 완전히 가려져 있으면 창을 다시 볼 때까지 완료를 늦게 알아챌 수 있습니다.

## 0.4.0 — Codex 기록에서 직접 상태 받기

**새 기능**
- ChatGPT 앱의 Codex 작업 상태를 앱이 직접 남기는 작업 기록에서 받습니다. 화면을 읽을 때보다 시작·완료 시점이 정확하고, 창을 숨겨 둬도 알아챕니다.
- 상태 카드에 "Codex 앱"으로 표시되고, 명령 실행·파일 고치기처럼 지금 하는 일도 함께 보입니다.
- 설정 창 **AI 연결 → 앱이 직접 남기는 기록**에서 켜고 끌 수 있고, 지금 작업 수와 마지막 소식 시각을 볼 수 있습니다.

**개인정보**
- 대화 내용은 읽어도 쓰지 않으며, 작업이 시작·완료됐다는 사실과 시각만 씁니다.

**버그 수정**
- 설정 창에서 앱 감지 스위치를 누를 때 잠깐 원래대로 돌아갔다가 바뀌던 깜빡임을 고쳤습니다.

## 0.3.4 — 전체 점검

**버그 수정**
- 간식·춤 같은 상호작용 도중 혼자 걷기 시작해 행동이 끊기거나, 춤추는 채로 미끄러지던 문제를 고쳤습니다. 이제 상호작용 중에는 산책을 쉽니다.
- 자는 우사기를 누르면 들어 올려지던 문제를 고쳤습니다. 이제 누르면 깨어납니다.
- 자는 중에 "도망가기"가 일어나면 잠든 채로 미끄러지던 문제를 고쳤습니다.
- AI 작업이 끝난 뒤 몇 분 동안 상호작용과 혼잣말이 멈춰 있던 문제를 고쳤습니다.
- 펫 크기가 아주 작거나 클 때 낮잠 자세가 어긋나던 문제를 고쳤습니다. 이제 어느 크기에서나 바닥에 누워 도라야키를 덮습니다.
- 긴 말이 말풍선 밖으로 넘치던 문제를 고쳤습니다.

**개선**
- 자는 동안과 상호작용 중에는 혼잣말을 하지 않습니다.

## 0.3.3 — 더블클릭 동작 정리

**바뀐 점**
- 펫을 더블클릭하면 Claude 앱이 열리던 기능을 없앴습니다. 빠르게 두 번 눌러도 쓰다듬기로만 반응합니다.
- Claude·ChatGPT 앱은 도는 AI 아이콘, 알림, 설정 창의 "앱 열기"로 열 수 있습니다.

## 0.3.2 — 싸움 동작

**새 기능**
- 싸움 동작(28프레임)을 넣었습니다. 정면을 보다가 주먹을 연타하고, 돌아서서 몸을 낮춰 버둥거리며 돌진합니다.
- 짧은 시간에 여러 번 찌르면(2.5초 안에 세 번 클릭) 이 동작을 합니다.

**개선**
- 여러 줄에 걸친 동작은 몸 중심에 맞춰 그려서, 주먹이나 효과선이 튀어나와도 몸이 흔들리지 않습니다.
- 이전 시트는 `pets\sprite-before-fight.png`로 남겨 두었습니다.

## 0.3.1 — 우사기 상호작용과 Windows 알림

**새 기능**
- 원작 속 우사기의 모습을 참고한 상호작용 8가지를 넣었습니다.
  - 쓰다듬기 (클릭)
  - "하아?!" (짧은 시간에 여러 번 찌르기)
  - 간식 먹기 "우마!" (우클릭 메뉴 **간식 주기**, 가끔 혼자서도)
  - 갑자기 춤추기, 도토리 닦기 (쉬고 있을 때 가끔)
  - 휘저으면 도망가기 (펫 근처에서 마우스를 빠르게 흔들면 잰걸음으로 달아남)
  - 도라야키 이불 낮잠 (3분 동안 컴퓨터를 안 쓰면)
  - 반기기 "야하!" (2분 넘게 자리를 비웠다 돌아오면)
- 설정 창 **상호작용**에서 하나씩 또는 한꺼번에 켜고 끌 수 있고, **지금 해 보기**로 바로 볼 수 있습니다.
- 알림이 Windows 정식 알림으로 바뀌었습니다. 알림 센터에서 눌러도 해당 앱이 열립니다. 이를 위해 시작 메뉴에 "우사기 펫" 바로 가기를 만듭니다.

**버그 수정**
- 알림이나 아이콘을 눌렀을 때 웹이 아니라 설치된 Claude·ChatGPT 앱이 확실히 열립니다.

## 0.3.0 — 설정 창(컨트롤센터)

**새 기능**
- 설정 창을 새로 만들었습니다. 우클릭·트레이 메뉴의 **설정 열기…**, 트레이 아이콘 더블클릭, 또는 UsagiPet.exe를 한 번 더 실행하면 열립니다.
  - **홈**: 지금 상태, Claude·GPT별 경과 시간, 자주 쓰는 설정, 연결 상태를 한 화면에 모았습니다.
  - **AI 연결**: 앱 감지 켜기·끄기와 감지 상태, Claude Code·Codex 연결·해제.
  - **말풍선**: 혼잣말·우사기어 해석 설정을 바꾸면 미리보기가 바로 바뀌고, 우사기어 사전을 볼 수 있습니다.
  - **모습·움직임**: 크기를 실제 크기로 미리 보고, 자동 산책·아이콘 돌리기·그림 시트를 바꿉니다.
  - **알림**: 알림 미리보기와 **이 알림 직접 받아 보기** 버튼.
  - **일반**: Windows 시작할 때 실행, 폴더 열기, 펫 숨기기·종료, 버전 정보.

**바뀐 점**
- 우클릭·트레이 메뉴를 7개 항목으로 줄였습니다. 나머지는 설정 창에 있습니다.
- 말풍선·상태 카드·AI 아이콘 테두리를 설정 창과 같은 크림색 디자인과 글꼴(Jua)로 바꿨습니다. 상태는 색과 모양(도는 테두리 / 깜빡임 + ? / ! / ✓)으로 함께 구분합니다.

**버그 수정**
- 펫을 켜기 전부터 AI가 일하고 있었으면, 상태가 바뀔 때까지 알아채지 못하던 문제를 고쳤습니다.

## 0.2.2 — 우사기 말투

**바뀐 점**
- 우사기가 외침으로만 말합니다 (야하·후응·우~라~·하아?·우마·우냐·우라우라). AI 소식을 전할 때만 뜻을 괄호 안에 적습니다.

## 0.1.4 — 첫 정비

**새 기능**
- 크기 메뉴와 **Windows 시작할 때 실행** 메뉴를 추가했습니다.
- Claude Code 작업 알림 연결을 메뉴에서 켜고 끌 수 있습니다. 여러 세션을 동시에 써도 되고, API 오류도 보여 줍니다.
- 트레이 아이콘이 펫 그림으로 바뀌고, 마우스를 올리면 지금 상태가 보입니다.

**개선**
- 모든 동작을 같은 크기로 그려, 프로펠러 비행 중 몸이 작아지던 현상을 고쳤고 점프가 실제로 떠오릅니다.
- 배율이 다른 모니터 사이로 옮길 때 창 크기가 변하던 현상을 막았고, 드래그가 더 부드러워졌습니다.
- 커서가 멀리 있을 때는 화면을 다시 그리지 않아 CPU 사용이 줄었습니다.
- 보안 설정을 끄지 않고도 펫 그림을 불러옵니다.

**버그 수정**
- 저장된 위치의 모니터가 없어졌거나 배율이 바뀌면 펫이 화면 밖에 남던 문제를 고쳤습니다. 이제 화면 안으로 다시 들어옵니다.
- Claude Code 연결을 설치할 때 읽을 수 없는 설정 파일을 덮어써 기존 설정이 사라질 수 있던 문제를 고쳤습니다.
