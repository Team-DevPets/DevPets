우사기 펫 — Windows 64비트

1. ZIP을 폴더째 모두 압축 해제하세요.
2. UsagiPet.exe를 더블클릭하세요. 펫 실행에는 Node.js 설치가 필요 없습니다.
3. 종료는 펫 우클릭 또는 트레이 메뉴에서 하세요.

크기: 우클릭 메뉴의 "크기"에서 작게·보통·크게·아주 크게를 고르세요.
자동 시작: 우클릭 메뉴의 "Windows 시작할 때 실행"을 체크하세요.
  (폴더를 다른 곳으로 옮겼다면 한 번 껐다 다시 켜세요.)

이미지 교체: 실행 파일 옆 pets 폴더에 11줄 형식의 PNG를 sprite.png라는 이름으로 넣으세요.
교체하지 않으면 내장 우사기 v1.10이 나옵니다. 이미지 변경은 실행 중에도 적용됩니다.
UsagiPet.exe만 따로 옮기지 말고 DLL·resources 등 폴더 전체를 함께 보관하세요.

작업 알림: 우클릭 메뉴에서 연결할 것을 체크하세요.
  - Claude 앱 / ChatGPT 앱 응답 감지: 기본으로 켜져 있어요 (데스크톱 앱이 답변 중이면 노트북).
  - Claude Code / Codex 작업 알림 연결: 체크한 뒤 해당 프로그램을 다시 시작하세요.
    Codex는 처음 한 번 Codex CLI에서 /hooks 로 펫 hook을 신뢰해 주세요.
hook 실행에는 Node.js가 필요합니다(없으면 메뉴가 안내합니다).
명령어로 하려면 이 폴더에서 node hooks/install.js를 실행하세요.
기본 사용법과 상태 점 설명은 README.md를 참고하세요.
